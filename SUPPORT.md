# Support

KDE ASCII Saver is a volunteer-maintained preview project. Help is best-effort;
no response time or long-term support period is guaranteed.

## Before opening an issue

1. Read the [installation guide](docs/INSTALLATION.md) and
   [troubleshooting guide](docs/TROUBLESHOOTING.md).
2. Search [existing issues](https://github.com/RobbyBobby77/kde-ascii-saver/issues)
   for the same symptom.
3. Confirm the issue still occurs on the latest release.
4. Run `kde-ascii-saverctl status` and collect only the relevant service logs.

Use the repository's bug form for reproducible defects and the feature form for
focused enhancements. General KDE Plasma configuration questions are better
suited to KDE's own support channels.

Include the KDE ASCII Saver version, distribution, Plasma version, Wayland or
X11, monitor setup, steps to reproduce, and expected versus observed behavior.
Redact usernames, hostnames, tokens, private artwork, and unrelated log output.

Do not report a suspected vulnerability in a public issue. Follow
[Security](SECURITY.md) instead.
